# The Bridge Mixed Reality Headset: A hands on Video.

*The Bridge MR Headset is from the fine folks at Occipital. It is currently the only inside out tracking mobile VR solution you can buy…*

![](/wiki/svgn/articles/media/svgn-88472101/000.jpg)

The Bridge MR Headset is from the fine folks at Occipital. It is currently the only inside out tracking mobile VR solution you can buy today with six degrees of freedom + it does Mixed Reality like Hololens, and it has a 3dof controller which makes using it far easier than using Hololens.

We spoke to Jacob Ervin, Product Manager at Occipital, to discuss the new Bridge Mixed Reality Headset available at https://bridge.occipital.com/
