So how much is it going to cost to get your first AR/VR device? The answer is $149, but that doesn’t include the headset portion yet.

Today Bestbuy is selling an iphone SE that usually costs $399 for $149, given that it can run ARkit which rivals Hololens which costs $3,000 dollars this is a bit of a steal. ARkit also rivals Google Tango! If you need an extra phone, for whatever reason, whether it’s for battery life, emergencies, or whatever important reason you might need to get an extra phone. It does not require a cellular subscription which means you can use it like an ipad, with only wifi. here is the link

Special note: ARkit is currently in the developer version of IOS, so if you are comfortable playing with a version of IOS that is still available go ahead and download it. Be warned however that beta software can have bugs, and you should probably not download beta software on a primary device. One example of buggy beta software is that my friend lost the ability to connect to wifi hotspots after downloading the ARkit beta version of iOS.
