GoDot's integration on Quest 3 represents a major leap for VR development by allowing users to build apps and games directly inside the headset without needing an external PC. This native support, available through Horizon OS (version 69 or higher), enables developers to work in a full-featured game engine, making it possible to create both 2D and immersive XR (extended reality) experiences entirely within the Quest 3. The app provides access to all the usual Godot engine features, such as GDScript code editing, debugging, live scene editing, and real-time profiling.

One standout feature is seamless multitasking. Developers can switch between the Godot Editor's 2D panel view and fully immersive VR windows, allowing for real-time testing and adjustments while staying within the same environment. This reduces the development friction typically encountered when switching between a PC and a VR device for testing.
